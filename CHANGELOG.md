# Changelog

## [0.0.41] - 2026-10-02

- Formatted snippet examples in README with descriptive headers and proper capitalization.

## [0.0.40] - 2026-10-01

- Dropped TypeScript and TSX snippet contributions and removed the `ts`/`typescript` keywords.
- Expanded the CSS `base` reset and refreshed base program bodies for JavaScript, Python, Rust, Go, and Java.
- Added the `hash21` helper to the GLSL `noise` snippet and renamed the uniform prefix to `uni`.
- Removed the `main` alias from Rust, Go, Java, and Python base snippets.
- Documented the full snippet catalog in the README and excluded local `code/` previews from the package.

## [0.0.39] - 2026-09-30

- Added `main` as an alias for base program snippets in Rust, Go, Java, and Python.

## [0.0.38] - 2026-09-30

- Fixed snippet availability across Rust and other supported languages.
- Removed redundant scope filters from extension snippets.

## [0.0.37] - 2026-09-30

- Added Open VSX namespace and publishing commands.
- Added local environment configuration templates.
- Updated extension metadata and platform links.

## [0.0.36] - 2025-10-20

- Added TypeScript, JavaScript, React, HTML, and Python snippets.
- Fixed snippet syntax and refreshed README context.

## [0.0.33] - 2023-03-14

## [0.0.32] - 2023-03-12
